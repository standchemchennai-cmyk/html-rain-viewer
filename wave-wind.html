Reading this map

Click the map to inspect any location. The time slider controls map colours, arrows, selected-point forecasts and tide plot together. All times are India Standard Time (IST).

The map is a sampled, interpolated approximation of model fields, not native-resolution forecast tiles. Coastal ocean colours can be extrapolated within a partly valid sample cell. This does not increase nearshore model accuracy. Wind arrows indicate travel direction; numerical direction is meteorological “from”.

Rain is modelled hourly total precipitation including showers, not rain-gauge observations. Historical model output is not measured weather. Tides use independent modelled sea-level forecasts including tidal effects; do not use for navigation.
